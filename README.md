# ☕ Coffee Shop Sales Analysis | Excel Dashboard

## 📌 Project Overview

This project focuses on analyzing coffee shop sales data using Microsoft Excel to identify sales trends, customer purchasing patterns, and product performance.

The project includes data cleaning, data analysis using Pivot Tables, and an interactive Excel dashboard to generate meaningful business insights.

The dataset contains **149,116 transactions** covering January to June 2023.

## 🎯 Project Objectives

* Analyze overall coffee shop sales performance.
* Identify monthly revenue trends.
* Find the best-performing products.
* Analyze sales by product category.
* Compare revenue across store locations.
* Understand customer purchasing patterns.
* Identify peak sales days and hours.
* Create an interactive Excel dashboard.

## 📊 Dataset Information

The dataset contains coffee shop transaction records with information such as:

* Transaction ID
* Transaction Date
* Transaction Time
* Store Location
* Product Category
* Product Type
* Product Detail
* Quantity
* Unit Price
* Revenue

**Total Records:** 149,116

**Analysis Period:** January 2023 – June 2023

## 🧹 Data Cleaning

The dataset was reviewed and prepared for analysis.

Key activities included:

* Checking missing values.
* Identifying duplicate records.
* Reviewing data formats.
* Checking numerical values.
* Organizing columns for analysis.
* Preparing clean data for Pivot Tables.
